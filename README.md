# Intelligent Text Analysis System

## Description
This project is a Python-based text analysis system that uses different pattern searching algorithms to analyze large text documents.

The system can:
- Find exact keyword matches
- Detect duplicate sentences
- Identify repeated phrases
- Show match positions
- Compare algorithm performance

---

## Algorithms Used
- Naive Search
- KMP Algorithm
- Rabin-Karp Algorithm
- Boyer-Moore Algorithm

---

## Technologies Used
- Python
- Tkinter
- Matplotlib

---

## Features
- GUI-based interface
- Case-sensitive search
- Case-insensitive search
- Performance comparison graphs
- Execution time analysis
- Memory usage analysis
